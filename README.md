# 한 번 더 (Hanbeonde) v2

보내기 전에 한 번 더, 내 말을 다듬어 주는 도구.
욕설·비속어·패드립·변형 은어·외모 비하 표현을 찾아내서 **보내기 전에 멈추고**, 원래 감정은 살린 **고운 말 3가지**로 바꿔 줘요.

| 버전 | 어디서 쓰나 | 폴더 |
|---|---|---|
| PC 웹 | 브라우저에서 바로: 텍스트 검사기, 메신저 체험, 대시보드, 단어 DB | `pc-web/` |
| 크롬 확장 프로그램 | 디스코드·슬랙·인스타그램 DM 등 **웹** 메신저 입력창 | `chrome-extension/` |
| 윈도우 트레이 앱 | **카카오톡 PC**, 디스코드·슬랙 데스크톱 등 PC 메신저 | `desktop/` |
| 안드로이드 키보드 | 휴대폰 카카오톡·인스타그램 등 모든 앱 | `android/` |
| 아이폰 키보드 | 위와 같음 (Mac + Xcode 필요) | `ios/` |

모든 버전이 **같은 단어 DB와 같은 감지 규칙**을 써요. 분석은 전부 기기 안에서만 하고, 입력한 문장은 저장하지도 보내지도 않아요. 기록에는 횟수와 감지된 표현만 남아요.

---

## 1. 감지 엔진

### 단어 DB
- `tools/외모비하_욕설_DB.xlsx` 의 **2,892줄 전부**를 넣었어요. 띄어쓰기만 다른 8쌍(예: `면상 박살` / `면상박살`)은 같은 표현이라 하나로 합쳐져 2,884개가 돼요.
- 여기에 핵심 욕설·패드립 토큰과 변형 606개를 더해 **모두 3,490개 표현**으로 검사해요.
- 엑셀의 심각도는 위험도로 이렇게 바뀌어요: 최상 → `CRITICAL`, 상 → `HIGH`, 중 → `MEDIUM`, 하 → `LOW`.

엑셀을 고친 뒤에는 이렇게 다시 만들면 모든 버전에 반영돼요.
```
pip install openpyxl
python3 tools/build_words.py
```
핵심 토큰, 변형 표, 오탐 예외 목록도 `tools/build_words.py` 맨 위에서 고칠 수 있어요.

### 변형 입력 탐지
| 변형 | 예 | 처리 |
|---|---|---|
| 한 글자씩 띄어쓰기 | `씨 발 련 아`, `느 금 마`, `돼 지 야` | 한 글자 어절이 이어지면 붙여서 검사 |
| 초성 | `ㅆㅂ련`, `ㅄ`, `ㅈㄴ`, `ㄴㄱㅁ` | 표준형으로 바꿔서 검사 |
| 영문·자판 | `c발`, `tlqkf`, `qudtls`, `ssibal` | 표준형으로 바꿔서 검사 |
| 숫자·기호 끼워 넣기 | `씨1발`, `씨.발.놈`, `씨x발`, `병1신`, `18놈` | 한글 사이 숫자·기호·영문 한 글자 제거 |
| 오탐 예외 | `시발점`, `돼지고기`, `껌 씹고`, `시바견`, `새끼손가락` | 감지하지 않음 |

### 순화안
문장의 감정(화남, 답답함, 장난, 놀람, 관심)과 표현 종류(패드립, 욕설, 외모 비하)를 보고 고운 말 3가지를 골라요.

### 출력 JSON
`analyze(문장)` 은 요청하신 규격 그대로 돌려줘요.
```json
{
  "is_harmful": true,
  "risk_level": "CRITICAL",
  "detected_words": ["씨발련아"],
  "category": "강한 욕설 및 비속어",
  "suggestions": ["너 때문에 정말 속상하고 화가 나", "일이 이렇게 돼서 너무 답답해", "다음부터는 주의해 줬으면 좋겠어"],
  "pc_ui_action": { "show_overlay": true, "highlight_target": "씨발련아" }
}
```
- 문제가 없으면 `is_harmful: false`, `risk_level: "NONE"`, 빈 목록, `category`·`highlight_target` 은 `null` 이에요.
- `show_overlay` 는 `MEDIUM` 이상일 때 `true` 예요. `LOW`(오징어, 메주 등)는 표시만 하고 멈추지 않아요.
- 위치와 설명까지 필요하면 `analyzeDetailed`(JS) / `analyze_detailed`(Python) 를 쓰세요.

| 언어 | 파일 | 확인 |
|---|---|---|
| JavaScript | `engine/hanbeonde-engine.js` | `node engine/test.js` (49개 시험 문장) |
| Python | `desktop/engine.py` | `python3 desktop/engine.py "씨 발 련 아"` |
| Java | `android/.../Engine.java` | 383개 문장에서 JS와 결과가 같은지 확인함 |
| Swift | `ios/Shared/Engine.swift` | Xcode에서 빌드 필요 (직접 빌드는 못 해 봄) |

## 2. PC 웹 버전 (`pc-web/`)
`pc-web/index.html` 을 브라우저로 열면 바로 돼요.
- **텍스트 검사기**: 쓰는 동안 위험한 부분이 위험도 색으로 칠해지고, 아래 패널에 위험도 뱃지·분류·순화안과 원클릭 교체 버튼이 있어요. 'JSON 결과 보기'로 규격 출력을 볼 수 있어요.
- **메신저 체험**: PC 메신저 화면에서 손을 멈추거나 Enter를 누르면 오버레이 위젯이 떠요.
- **대시보드**: 최근 7일 감지 그래프, 순화 전환율, 자주 쓴 표현, 칭찬 미션.
- **단어 DB**: 3,490개 표현 검색.

## 3. 크롬 확장 프로그램 (`chrome-extension/`)
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → `chrome-extension` 폴더 선택
3. 디스코드·슬랙 등 웹 메신저에서 입력하면 입력창 오른쪽 아래에 위험도 알약이 뜨고, 손을 멈추거나 Enter를 누르면 경고 위젯이 떠요.
   - 순화안을 누르면 입력창 문장이 바뀌고, Enter를 누르면 보내져요.
   - '그대로 보내기'를 누른 뒤 Enter를 한 번 더 누르면 그대로 보내져요.
4. 툴바의 아이콘 → 켜기/끄기, 이 사이트에서 끄기, 대시보드 열기

## 4. 윈도우 트레이 앱 (`desktop/`) — 카카오톡 PC용
- 대상 프로그램: 카카오톡, 디스코드, 슬랙, 라인, 텔레그램, 팀즈 (트레이 메뉴에서 '모든 프로그램'도 가능)
- 대상 창에서 **Enter**를 누르면 먼저 가로채서 검사해요. 안전하면 그대로 보내지고, 위험하면 입력창 위에 경고 위젯이 떠요. Shift+Enter(줄바꿈)는 건드리지 않아요.
- 카카오톡처럼 입력창 글자를 직접 읽을 수 있는 프로그램은, 입력하다 손을 멈춰도 위험도 알약과 경고를 띄워요.
- 트레이 아이콘 → **대시보드 열기**로 기록을 그래프로 봐요.

**exe 만들기 (추천):** 이 폴더를 GitHub 저장소에 올리면 `.github/workflows/build-windows.yml` 이 `Hanbeonde.exe` 를 만들어 줘요. Actions 탭 → '윈도우 앱 만들기' → Artifacts의 **hanbeonde-windows**.

**직접 실행:** 윈도우에 Python 3.10 이상을 설치하고
```
cd desktop
pip install -r requirements.txt
python hanbeonde_tray.py
```

> 윈도우 앱은 제 작업 환경이 윈도우가 아니라서 실제 카카오톡 PC에서는 시험하지 못했어요. 감지 엔진과 버튼 흐름은 시험했어요. 처음 실행할 때 문제가 있으면 증상을 알려 주세요.
> 카카오톡을 관리자 권한으로 실행했다면 이 앱도 관리자 권한으로 실행해야 Enter를 가로챌 수 있어요.

## 5. 휴대폰 키보드
- **안드로이드:** `.github/workflows/build-apk.yml` 이 APK를 만들어요 (Actions → '안드로이드 APK 만들기' → **hanbeonde-apk**). 설치 후 '한 번 더' 앱에서 키보드를 켜고 선택하세요. 자세한 순서는 앱 첫 화면에 있어요.
- **아이폰:** Xcode에서 앱 + Custom Keyboard Extension 타깃을 만들고 `ios/` 파일을 넣어요. `ios/Shared/` 의 `Engine.swift`, `Stats.swift`, `Hangul.swift`, `words.json` 은 **앱과 키보드 타깃 둘 다** 체크하세요. App Groups(`group.com.hanbeonde.shared`)를 두 타깃에 켜고, 키보드 설정에서 '전체 접근 허용'을 켜면 리포트가 공유돼요.

## 한계
- 카카오톡·인스타그램 **휴대폰 앱**의 전송 버튼은 그 앱의 버튼이라 키보드가 막을 수 없어요. 그래서 휴대폰에서는 손을 멈춘 순간 경고가 떠요. PC에서는 Enter를 가로채서 실제로 멈출 수 있어요.
- 감지는 단어 DB와 규칙으로 해요. 목록에 없는 새 표현이나 문맥은 놓칠 수 있고, 드물게 괜찮은 말을 잡을 수도 있어요. 그럴 때는 엑셀이나 `tools/build_words.py` 의 예외 목록에 추가하세요.
- DB 원본 표현 중에는 `강남미인`, `화장빨`, `영포티` 처럼 맥락에 따라 괜찮을 수 있는 말도 있어요. 엑셀 심각도를 그대로 따랐어요.
